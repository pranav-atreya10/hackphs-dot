Native iPhone App · ATHARV/ios/SkySentryCam

Native iOS SkySentryCam Architecture & Xcode Guide

Built exclusively with SwiftUI, AVFoundation, CoreImage, Security, and URLSession (iOS 17+, bundle ID com.skysentry.camera)—zero third-party Swift packages, builds completely offline.

StreamController.swift

Single-Flight 15 fps Uploader

Captures 1280×720 rear-camera frames, scales long edge to 640 px (JPEG quality 0.6) off the main thread, and enforces at most 1 HTTP upload in flight so slow cellular links shed rate instead of adding latency.

Settings.swift · Keychain

Hardware Keychain Security

Migrates legacy defaults and stores both api-key and persistent UUID device-id in the iOS Keychain under kSecAttrAccessibleWhenUnlockedThisDeviceOnly—never synced to iCloud or backups.

SkyAPI.swift · Ephemeral TLS

Airport-Bound Ingress

Uses URLSessionConfiguration.ephemeral (zero disk cache) posting to /api/camera-config, /api/camera-frame, and /api/camera-stop with x-api-key, x-airport, x-camera-device, and x-camera-source: live.

OverlayView.swift · Fail-Closed

Server-Authoritative HUD

Renders surveyed terracotta corridor masks, bird/drone/unknown tracks, and flock ETAs across Fill and Fit modes—and automatically expires annotations via remaining_ms if fresh server results stop.

Build & run in Xcode or Simulator (ATHARV/ios)

Open ATHARV/ios/SkySentryCam.xcodeproj in Xcode 16+, choose the SkySentryCam scheme, and run on an iPhone or Simulator. In Simulator (no rear camera), select Demo sky—synthetic previews never upload to the live server or trigger tower alerts.

cd ATHARV/ios
xcodebuild -project SkySentryCam.xcodeproj -scheme SkySentryCam \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build

# Optional launch arguments (ephemeral, never persisted to UserDefaults/Keychain):
xcrun simctl launch booted com.skysentry.camera \
  -autoOpenCamera YES -autoStart YES -apiKey <key> -serverURL https://your-host.example -cameraId sim-1
Provisioning on a physical iPhone with a free Apple ID
  1. Connect the iPhone via USB-C/Lightning, tap Trust, and enable Settings → Privacy & Security → Developer Mode (iOS 16+).
  2. In Xcode, add your Apple ID under Settings → Accounts, then select target SkySentryCam → Signing & Capabilities and pick your Personal Team (adjust bundle ID if needed, e.g. com.yourname.skysentry).
  3. Build & Run to the iPhone, then trust your developer certificate under Settings → General → VPN & Device Management. Free Personal Team builds refresh every 7 days.
  4. Use https:// for remote deployments; iOS App Transport Security (NSAllowsLocalNetworking) permits plain http:// only on isolated LAN addresses.
